Python Basic Programs & Code Snippets

Dive into our collection of Python programming snippets. Python's simple syntax and readability make it an excellent choice for beginners, while its powerful libraries make it a top language for data science, web development, and automation. The programs below cover essential Python topics including list comprehensions, file handling, string manipulation, and functional programming concepts. Use these examples to quickly master Python programming techniques.

1. Comments and Inputs

Concept: Introduces single and multi-line comments in Python, along with how to read user input using the built-in input() function.

program_1.py


#Python Single Line comments
""""
Python Multiline Comments
"""
'''
Python Multiline Comments
'''
#Python Input
name=input("Enter name: ") # input function
#Python Output Statement
print(name)
#by default all inputs in string format
#type casting
age=int(input("Enter Age"))
print(age)
#it returns the given variable data type
print(type(age))
Analysis
  • Time Complexity: O(1) - Constant time.
  • Space Complexity: O(1) - Constant space.
Expected Output:
Enter name: John Enter Age: 25 25

3. Variable Assignment

Concept: Shows how Python automatically infers the data type based on the assigned value (dynamic typing).

program_3.py


#if you are assign any data to variables it takes appropriate data type

name="SrinivasaRao"
age=35
course="Python"
fees=3000.50
is_active=True

  • Time Complexity: O(1)
  • Space Complexity: O(1)

Code: 100 Name: SrinivasaRao

8. Arithmetic Operators

Concept: Demonstrates standard arithmetic operations in Python including addition, subtraction, multiplication, and power/exponentiation.

program_8.py


#Arithmatic Operators
# a=45
# b=2
a = int(input("Enter a value"))
b = int(input("Enter b value"))
print("A + B=", a+b) # Addition
print("{}+{}={}".format(a, b, a+b))
print("A - B=", a-b) # Subtraction
print("A X B=", a*b) # Multiplication
print("A/B=", a/b) # Division
print("A//B=", a//b) # Rounded to floor
print("A%B=", a%b) # Moduls
print("2 Power 8=", 2**8) # Exponentiation**
Analysis
  • Time Complexity: O(1)
  • Space Complexity: O(1)
Expected Output:
Enter a value: 45 Enter b value: 2 Addition : 47 Sub : 43 Mul : 90 Power : 2025

11. Identity and Membership Operators

Concept: Uses 'is' and 'is not' to compare memory locations, and 'in' and 'not in' to check for element presence inside collections or strings.

program_11.py


#Identity Operators

b=35
print(a is b) #False
print (a is not b) #True

#Membership Operators
x=[1,2,3,4,5]
print (3 in x) #True
print(3 not in x) #False

  • Time Complexity: O(N) for membership tests on lists.
  • Space Complexity: O(1)

False True True False

15. Bitwise Operators

Concept: Performs bit-level operations (AND, OR, NOT, XOR, Shifts) on integer operands.

program_15.py


# Python program to show
# bitwise operators
a = 10
b = 4

# Print bitwise AND operation
print("a & b =", a & b)
# Print bitwise OR operation
print("a | b =", a | b)
# Print bitwise NOT operation
print("~a =", ~a)
# print bitwise XOR operation
print("a ^ b =", a ^ b)
Analysis
  • Time Complexity: O(1)
  • Space Complexity: O(1)
Expected Output:
a & b = 0 a | b = 14 ~a = -11 a ^ b = 14 a >> 1 = 5 a << 1 = 20
