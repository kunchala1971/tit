Welcome to our comprehensive collection of C programming examples. C is a powerful general-purpose programming language that is widely used for system programming and embedded systems. 1. Single Character Input and Output

Concept: Demonstrates reading and writing individual characters efficiently using standard library functions getchar() and putchar() from <stdio.h>.

character_io.c


#include <stdio.h>

int main() {
    char c; // Variable to hold the character
    
    printf("Enter any character: ");
    
    // getchar() reads a single character from standard input
    c = getchar(); 
    
    printf("The Given Character is: ");
    
    // putchar() writes a single character to standard output
    putchar(c); 
    
    printf("\n");
    return 0;
}
Analysis
  • Time Complexity: O(1) - The program executes in constant time regardless of input.
  • Space Complexity: O(1) - Only a single char variable is allocated in memory.
Output Console
Enter any character: A
The Given Character is: A
