JSTL Advanced Libraries

JSTL Formatting (fmt), SQL & XML Tag Libraries

Master internationalization (i18n), locale currency/date formatting, database prototyping, and XML XPath parsing inside JSP pages using specialized JSTL tag libraries.

By KSR 12 min read Updated September 2026

Beyond Core logic and Functions, JSTL provides specialized tag libraries for Formatting & Internationalization (fmt), Database SQL operations (sql), and XML / XPath document processing (x).

1. JSTL Formatting Tags Reference (fmt:)

The JSTL Formatting tag library provides internationalization (i18n) support, allowing applications to format numbers, currencies, dates, and times according to local user preferences and regional resource bundles.

<%@ taglib uri="http://java.sun.com/jsp/jstl/fmt" prefix="fmt" %>
Tag Purpose & Description Example Usage Syntax
<fmt:formatNumber> Formats numeric values as currency, percentage, or specific decimal precision. <fmt:formatNumber value="${price}" type="currency" currencySymbol="₹" />
<fmt:parseNumber> Parses a formatted string value into a numeric variable. <fmt:parseNumber value="1,250.50" var="num" />
<fmt:formatDate> Formats date and time objects according to specified patterns or locale styles. <fmt:formatDate value="${now}" pattern="dd-MM-yyyy HH:mm:ss" />
<fmt:parseDate> Converts a formatted string date into a Java Date object. <fmt:parseDate value="2026-09-30" pattern="yyyy-MM-dd" var="parsedDate" />
<fmt:setLocale> Explicitly sets the active locale for number, date, and message formatting. <fmt:setLocale value="en_IN" />
<fmt:bundle> Loads an i18n resource bundle scoped within its body. <fmt:setBundle basename="messages" var="lang" />
<fmt:message key="welcome.msg" bundle="${lang}" />
<fmt:setBundle> Loads a resource bundle and stores it in a configuration variable.
<fmt:message> Retrieves and prints a localized text message key from a loaded resource bundle. <fmt:message key="label.username" />
<fmt:timeZone> Specifies a target time zone for date/time formatting within its body block. <fmt:timeZone value="Asia/Kolkata"> ... </fmt:timeZone>
<fmt:setTimeZone> Sets the default time zone used for formatting dates. <fmt:setTimeZone value="IST" />
<fmt:requestEncoding> Sets the character encoding used to decode HTTP request form parameters (e.g., UTF-8). <fmt:requestEncoding value="UTF-8" />

2. JSTL SQL Tags Reference (sql:)

JSTL SQL tags allow performing database operations (SELECT, INSERT, UPDATE, DELETE) directly within JSP pages.

Best Practice Note: Direct database queries inside JSP pages are intended primarily for rapid prototyping, learning, or simple reporting. Enterprise applications should keep SQL queries in backend DAO/Service layers (MVC pattern).
<%@ taglib uri="http://java.sun.com/jsp/jstl/sql" prefix="sql" %>
Tag Purpose & Description Syntax Example
<sql:setDataSource> Configures and establishes a JDBC database connection pool/driver. <sql:setDataSource var="db" driver="com.mysql.cj.jdbc.Driver" url="jdbc:mysql://localhost:3306/mydb" user="root" password="pass" />
<sql:query> Executes a SQL SELECT query and stores the resulting ResultSet in a variable. <sql:query dataSource="${db}" var="rs"> SELECT * FROM users </sql:query>
<sql:update> Executes SQL data modification statements (INSERT, UPDATE, DELETE). <sql:update dataSource="${db}" var="count"> UPDATE users SET status='Active' WHERE id=? <sql:param value="10" /> </sql:update>
<sql:param> Sets parameter values in a parameterized SQL query to prevent SQL injection vulnerabilities. <sql:param value="${userId}" />
<sql:dateParam> Sets date/time parameter values in a SQL statement. <sql:dateParam value="${dateObj}" type="timestamp" />
<sql:transaction> Wraps multiple <sql:update> tags in a single atomic database transaction. <sql:transaction dataSource="${db}"> ... </sql:transaction>

3. JSTL XML Tags Reference (x:)

The JSTL XML tag library allows parsing, evaluating XPath expressions, transforming XSLT, and navigating XML documents directly inside JSP pages.

<%@ taglib uri="http://java.sun.com/jsp/jstl/xml" prefix="x" %>
Tag Purpose & Description Syntax Example
<x:parse> Parses XML text or document file and saves it as a DOM document object. <x:parse xml="${xmlData}" var="doc" />
<x:out> Evaluates an XPath expression against an XML document and outputs the result. <x:out select="$doc/bookstore/book[1]/title" />
<x:set> Stores the result of an XPath expression into a variable. <x:set select="$doc/bookstore/book" var="books" />
<x:if> Evaluates an XPath condition and renders its body if true. <x:if select="$doc//book[@price > 50]"> Premium Book </x:if>
<x:forEach> Iterates over XML node sets matching an XPath expression. <x:forEach select="$doc/bookstore/book" var="b"> <x:out select="$b/title" /> </x:forEach>
<x:choose> Multi-branch decision wrapper for XPath evaluations. <x:choose>
  <x:when select="$doc/user/role = 'admin'">Admin</x:when>
  <x:otherwise>Guest</x:otherwise>
</x:choose>
<x:when> Individual XPath conditional branch inside <x:choose>.
<x:otherwise> Fallback branch when all <x:when> XPath conditions evaluate to false.
<x:transform> Applies XSLT stylesheet transformation to an XML document. <x:transform xml="${xmlData}" xslt="${xsltStyle}" />

4. Master Tag Library URI Reference Summary

Library Type Prefix Standard Taglib URI
Core Tags c http://java.sun.com/jsp/jstl/core
EL Functions fn http://java.sun.com/jsp/jstl/functions
Formatting & i18n fmt http://java.sun.com/jsp/jstl/fmt
Database SQL sql http://java.sun.com/jsp/jstl/sql
XML Processing x http://java.sun.com/jsp/jstl/xml
