JSTL Core Tags & EL Functions Complete Guide

Eliminate complex Java scriptlets (<% %>) from your JSP pages! Master all 14 JSTL Core Tags and 16 Expression Language (EL) string manipulation functions.

By KSR 14 min read Updated September 2026

JSTL (JavaServer Pages Standard Tag Library) is a standardized collection of predefined tags that handle common web programming tasks—such as variable creation, conditional branching, collection iteration, and string manipulation—without writing raw Java scriptlets.

1. Why JSTL? Scriptlets vs JSTL Comparison

Traditional JSP development relied heavily on Java scriptlets (<% ... %>), mixing backend Java code directly with HTML template markup. This approach leads to unmaintainable code and security risks (such as Cross-Site Scripting vulnerabilities).

Without JSTL (Scriptlets)

Mixing Java code with HTML:

<%
  String name = "Ravi";
%>
<h2>Welcome <%= name %></h2>
With JSTL & EL

Declarative HTML-like tag syntax:

<%@ taglib uri="http://java.sun.com/jsp/jstl/core" prefix="c" %>

<c:set var="name" value="Ravi" />
<h2>Welcome <c:out value="${name}" /></h2>

2. JSTL Core Tags Reference (c:)

To use JSTL Core tags in a JSP page, include the taglib directive at the top of your file:

<%@ taglib uri="http://java.sun.com/jsp/jstl/core" prefix="c" %>
Tag Purpose & Description Practical Syntax Example
<c:out> Safely outputs the result of an expression and automatically escapes XML/HTML characters to prevent XSS attacks. <c:out value="${student.name}" default="Guest" />
<c:set> Assigns a value to a variable in a specified scope (page, request, session, or application). <c:set var="userRole" value="Admin" scope="session" />
<c:remove> Removes a variable from a specified scope. <c:remove var="tempToken" scope="session" />
<c:catch> Catches runtime exceptions thrown in its body and assigns the error to a variable. <c:catch var="ex"> <% int i = 10/0; %> </c:catch>
<c:if> Evaluates a boolean condition and executes its body content only if true. <c:if test="${age >= 18}"> <p>Eligible to Vote</p> </c:if>
<c:choose> Acts like a Java switch statement to handle multi-branch conditionals.
<c:choose>
  <c:when test="${score >= 90}">Grade A</c:when>
  <c:when test="${score >= 75}">Grade B</c:when>
  <c:otherwise>Grade C</c:otherwise>
</c:choose>
<c:when> Defines a specific conditional branch inside <c:choose>.
<c:otherwise> Default fallback branch when all <c:when> conditions are false.
<c:forEach> Iterates over arrays, collections (Lists, Sets), Maps, or a numeric range. <c:forEach var="item" items="${productList}"> ${item.name} </c:forEach>
<c:forTokens> Iterates over tokens in a string delimited by specific characters. <c:forTokens items="Red,Green,Blue" delims="," var="color"> ${color} </c:forTokens>
<c:import> Retrieves and embeds content from another URL or local resource file into the JSP response. <c:import url="http://api.example.com/data" />
<c:param> Attaches request parameters to <c:url> or <c:import> tags. <c:param name="id" value="101" />
<c:redirect> Redirects the browser client to a target URL. <c:redirect url="/login.jsp" />
<c:url> Formats a URL with proper context path prefixing and URL encoding for session tracking. <c:url value="/profile.jsp" var="profileUrl" />

3. JSTL Functions Reference (fn:)

JSTL functions provide powerful string transformation and collection inspection methods directly within Expression Language (${...}). Include the functions taglib directive to enable them:

<%@ taglib uri="http://java.sun.com/jsp/jstl/functions" prefix="fn" %>
Function Purpose & Description EL Expression Example
fn:contains() Checks if a string contains a specified substring (case-sensitive). ${fn:contains(title, "Java")}
fn:containsIgnoreCase() Checks if a string contains a substring ignoring character case. ${fn:containsIgnoreCase(title, "java")}
fn:startsWith() Tests whether a string begins with a specified prefix. ${fn:startsWith(url, "https://")}
fn:endsWith() Tests whether a string ends with a specified suffix. ${fn:endsWith(filename, ".pdf")}
fn:escapeXml() Escapes XML/HTML special characters in a string. ${fn:escapeXml("")}
fn:indexOf() Returns the 0-based index of the first occurrence of a substring. ${fn:indexOf(email, "@")}
fn:join() Combines array elements into a single string joined by a separator. ${fn:join(strArray, ", ")}
fn:length() Returns the character length of a string or element count of a collection. ${fn:length(userList)}
fn:replace() Replaces occurrences of a substring with another string. ${fn:replace(text, "Servlet", "JSP")}
fn:split() Splits a string into an array based on a delimiter character. ${fn:split(csvData, ",")}
fn:substring() Extracts a substring between start and end indexes. ${fn:substring(code, 0, 4)}
fn:substringAfter() Returns the part of a string following a specified substring. ${fn:substringAfter(email, "@")}
fn:substringBefore() Returns the part of a string prior to a specified substring. ${fn:substringBefore(email, "@")}
fn:toLowerCase() Converts all characters in a string to lowercase. ${fn:toLowerCase(name)}
fn:toUpperCase() Converts all characters in a string to uppercase. ${fn:toUpperCase(name)}
fn:trim() Removes leading and trailing whitespace from a string. ${fn:trim(inputString)}
